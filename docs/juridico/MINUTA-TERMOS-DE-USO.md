2. **Conta e usuários.** A clínica responde pelos usuários que cadastra e pelo uso das credenciais; deve ativar a verificação em duas etapas para quem acessa dados clínicos.
3. **Dados.** A clínica é controladora dos dados de pacientes (ver contrato de operador). A plataforma não acessa dados clínicos no uso normal.
4. **Uso proibido.** Inserir dados sem base legal; compartilhar credenciais; tentar acessar dados de outra clínica; usar o sistema para fins ilícitos.
5. **Responsabilidade profissional.** O sistema é ferramenta de apoio. Decisões clínicas, registros e cumprimento das normas do conselho profissional são responsabilidade dos profissionais. **Recibos emitidos pelo sistema não são documentos fiscais.**
